# Sumi 墨
Next.js 14 + TypeScript + Tailwind manga reader on the MangaDex API.

    npm install && npm run dev      # http://localhost:3000

Reader keys: arrows / space (paged), F fullscreen, H hide controls.
Progress, library and reader settings live in localStorage.
